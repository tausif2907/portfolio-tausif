# Tausif Ansari | Interactive 3D Portfolio

Welcome to my personal developer portfolio! This is a fully animated, interactive web experience built to showcase my latest projects, technical skills, and design aesthetics. It leverages scroll-based animations and 3D rendering to provide an engaging user experience.

---

## 🚀 Tech Stack

| Technology       | Description                                  |
| ---------------- | -------------------------------------------- |
| **React (Vite)** | Lightning-fast development and optimized builds |
| **Tailwind CSS** | Utility-first styling for a sleek, modern UI |
| **GSAP**         | Smooth, complex scroll-based animations      |
| **Three.js**     | Interactive 3D scenes via React Three Fiber  |

## 🏁 Getting Started

If you'd like to run this portfolio locally on your own machine:

```bash
# Clone the repository
git clone https://github.com/tausif2907/portfolio-tausif.git

# Navigate into the directory
cd portfolio-tausif

# Install the dependencies
npm install

# Start the local development server
npm run dev
```
Open `http://localhost:5173` in your browser to view the site.
